# [Dreamhack] rev-basic-8 핵심 연산 구조 분석

## 1. 개요 및 디컴파일 분석

### `sub_140001000()` 디컴파일 코드

```c
__int64 __fastcall sub_140001000(__int64 a1)
{
    int i;

    for ( i = 0; (unsigned __int64)i < 0x15; ++i ) // i = 0부터 20까지 (총 21바이트)
    {
        if ( (unsigned __int8)(-5 * *(_BYTE *)(a1 + i)) != byte_140003000[i] )
            return 0LL;
    }
    return 1LL;
}

```

* **입력 검증 수식**:

$$(-5 \times a1[i]) \pmod{256} == \text{byte\_140003000}[i]$$


* **의미**: 입력 문자 $a1[i]$에 $-5$를 곱한 뒤 8비트(`unsigned __int8`) 범위로 캐스팅한 결과가 정답 메모리 데이터 배열과 일치하는지 검증합니다.

## 2. 모듈러 연산과 곱셈 역원(Modular Inverse) 유도

### 단순 나눗셈이 불가능한 이유

* 컴퓨터의 정수 연산 환경에서는 $-5$로 나누었을 때 소수점 손실 및 언더플로우가 발생하므로 단순 나눗셈을 사용할 수 없습니다.
* 1바이트 데이터 타입(`unsigned __int8`)의 특성에 따라 $\pmod{256}$ 유한체 공간에서의 **곱셈 역원**을 구해서 곱해주는 방식을 적용해야 합니다.

---

### 모듈러 곱셈 역원 구하기 (확장 유클리드 호제법)

구하고자 하는 모듈러 방정식:


$$-5 \times K \equiv 1 \pmod{256}$$

$-5 \equiv 251 \pmod{256}$ 이므로, 다음 합동식을 만족하는 $K$를 탐색합니다:


$$251 \times K \equiv 1 \pmod{256}$$

#### 1단계: 유클리드 호제법으로 나눗셈 수행

$$256 = 251 \times 1 + 5$$

$$251 = 5 \times 50 + 1$$

#### 2단계: 나머지를 기준으로 거꾸로 대입 (역산)

$$1 = 251 - 5 \times 50$$

$$5 = 256 - 251 \times 1 \quad \text{을 위 식에 대입}$$

$$1 = 251 - (256 - 251 \times 1) \times 50$$

$$1 = 251 \times 51 - 256 \times 50$$

#### 3단계: $\pmod{256}$ 연산 적용

$$251 \times 51 - 256 \times 50 \equiv 1 \pmod{256}$$

$$-256 \times 50 \equiv 0 \pmod{256} \text{ 이므로},$$

$$251 \times 51 \equiv 1 \pmod{256} \quad \implies \quad -5 \times 51 \equiv 1 \pmod{256}$$

> **결론**: $\pmod{256}$ 공간에서 **$-5$의 모듈러 곱셈 역원은 $51$** 입니다.

역산 수식:


$$a1[i] = (data[i] \times 51) \pmod{256}$$

#### ① $i = 0$ 일 때 ($data[0] = 0\text{xAC} = 172_{(10)}$)

* $a1[0] = (172 \times 51) \pmod{256}$
* $172 \times 51 = 8772$
* $8772 = 256 \times 34 + 68$
* **결과**: $a1[0] = \mathbf{68_{(10)}} \rightarrow \mathbf{0x44 \ (\text{'D'})}$

#### ② $i = 1$ 일 때 ($data[1] = 0\text{xF3} = 243_{(10)}$)

* $a1[1] = (243 \times 51) \pmod{256}$
* $243 \times 51 = 12393$
* $12393 = 256 \times 48 + 105$
* **결과**: $a1[1] = \mathbf{105_{(10)}} \rightarrow \mathbf{0x69 \ (\text{'i'})}$

#### ③ $i = 2$ 일 때 ($data[2] = 0\text{x0C} = 12_{(10)}$)

* $a1[2] = (12 \times 51) \pmod{256}$
* $12 \times 51 = 612$
* $612 = 256 \times 2 + 100$
* **결과**: $a1[2] = \mathbf{100_{(10)}} \rightarrow \mathbf{0x64 \ (\text{'d'})}$

## 4. 알고리즘 의사코드 (Pseudocode Concept)

가이드라인에 따라 완제 스크립트 대신 모듈러 곱셈 역원을 활용한 알고리즘 의사코드 스니펫을 작성합니다.

```python
# 모듈러 곱셈 역원 기반 역산 의사코드

# -5의 mod 256 공간 상 곱셈 역원 K = 51
inverse_key = 51

for i in range(len(data)):
    # 역원을 곱해준 후 8비트 마스킹(& 0xFF) 수행
    char_code = (data[i] * inverse_key) & 0xFF
    a1.append(char_code)

```

## 5. 핵심 정리

1. **모듈러 공간에서의 역연산**: 1바이트 공간($\pmod{256}$) 내에서 계수가 곱해진 선형 방정식은 단순히 나눗셈을 수행하는 대신 곱셈 역원(Modular Inverse)을 유도하여 풀이합니다.
2. **확장 유클리드 호제법**: $a \cdot x \equiv 1 \pmod m$ 형태의 방정식은 유클리드 호제법의 역산 과정을 통해 역원 $x$를 정확히 계산할 수 있습니다.
