# 1. x86-64 어셈블리 (Assembly Language)

## 1-1. 어셈블리 언어 개요

* **어셈블리 언어**: 컴퓨터의 기계어(Machine Code)와 1:1로 대응되는 사람이 읽을 수 있는 저수준 프로그래밍 언어.
* **문법 종류**: Intel 문법 (가독성이 좋아 Windows 및 x86 리버싱에서 주력으로 사용) 및 AT&T 문법 (GNU/Linux 개발 도구에서 주로 사용).
  * *본 노트는 **Intel 문법 + x86-64 아키텍처**를 기준으로 작성되었습니다.*

### 기본 구조 (Opcode & Operand)

```assembly
[명령어(Opcode)] [목적지 피연산자(Destination)], [원본 피연산자(Source)]
예) mov eax, 3   ; EAX 레지스터에 3을 대입

```

| 명령어 예시 | 피연산자 개수 | 역할 설명 |
| --- | --- | --- |
| `mov eax, 3` | 2 | `EAX` 레지스터에 3을 대입 |
| `push rbp` | 1 | `RBP` 레지스터 값을 스택에 저장 |
| `add rax, 0x30` | 2 | `RAX` 레지스터 값에 `0x30`을 더함 |
| `ret` | 0 | 현재 함수를 종료하고 호출한 위치로 복귀 |
| `imul rax, rdx, 0x3` | 3 | `RDX * 3` 결과를 `RAX`에 저장 |

## 1-3. 피연산자 표기법 및 크기 지정자 (`TYPE PTR`)

### 메모리 크기 지정자

메모리 피연산자는 대괄호 `[]`로 주소를 둘러싸며, 연산할 데이터의 정확한 크기를 지시하기 위해 지정자(`TYPE PTR`)를 붙입니다.

* **`BYTE PTR`**: 1바이트 (8비트)
* **`WORD PTR`**: 2바이트 (16비트)
* **`DWORD PTR`**: 4바이트 (32비트)
* **`QWORD PTR`**: 8바이트 (64비트)

>  **주의**: `mov [rdi], eax`처럼 크기가 불분명할 경우 컴파일러/어셈블러가 에러를 발생시킬 수 있으므로, `mov DWORD PTR [rdi], eax`와 같이 메모리 참조 크기를 명확히 지정하는 것이 좋습니다.

### 피연산자 약어 표

| 약어 | 의미 |
| --- | --- |
| **r8 / r16 / r32 / r64** | 8 / 16 / 32 / 64비트 크기의 범용 레지스터 |
| **imm8 / imm16 / imm32 / imm64** | 8 / 16 / 32 / 64비트 크기의 즉시값 (Immediate Value / 상수) |
| **r/m8, r/m16, r/m32, r/m64** | 해당 비트 크기의 범용 레지스터 또는 메모리 주소 영역 |

## 1-4. 데이터 저장 및 이동 명령어

### 1) `mov <destination>, <source>`

`<source>`의 값을 `<destination>`으로 복사/대입합니다.

```assembly
mov rdi, rax                 ; RAX의 값을 RDI에 복사
mov edi, 0xdeadbeef          ; EDI에 32비트 16진수 상수 대입
mov BYTE PTR [var], 0x10     ; var 메모리 주소에 1바이트 크기 0x10 저장
mov rbp, [rbp + 16]          ; [RBP + 16] 주소에 저장된 메모리 값을 RBP에 복사
mov rax, [rdi]               ; RDI가 가리키는 메모리 주소의 실제 데이터를 RAX에 저장

```

---

### 2) `lea <destination>, <source>` (Load Effective Address)

메모리에 접근하여 데이터 값을 가져오는 것이 아니라, 계산된 **유효 주소(Effective Address) 그 자체**를 레지스터에 저장합니다.

```c
// C 언어 주소 연산 예시
int arr[5] = {10, 20, 30, 40, 50};
int *ptr = &arr[2]; // arr[2]의 주소값을 ptr에 저장

```

```assembly
; 위 C 언어 코드를 어셈블리로 표현
lea rbx, [arr]               ; RBX = arr 배열 시작 주소
mov rcx, 2                   ; RCX = 인덱스 2
lea rax, [rbx + rcx * 4]     ; RAX = RBX + (2 * 4) -> arr[2]의 주소값 자체를 RAX에 저장

```

> 💡 **`mov` vs `lea` 핵심 차이**
> * `mov rax, [rbx + rcx * 4]`: 해당 계산된 메모리 주소로 **이동하여 실제 저장된 값**을 가져옴
> * `lea rax, [rbx + rcx * 4]`: 메모리에 접근하지 않고, **계산된 주소 값 자체**를 가져옴
> 
>

## 1-5. 산술 및 논리 연산 명령어

### 1) 산술 연산 (`add`, `sub`, `inc`, `dec`, `imul`, `idiv`)

* **`add <dst>, <src>`**: `<dst> = <dst> + <src>`
* **`sub <dst>, <src>`**: `<dst> = <dst> - <src>`
* **`inc <reg/mem>`**: 피연산자 값 1 증가
* **`dec <reg/mem>`**: 피연산자 값 1 감소

#### 곱셈 (`mul` / `imul`)

곱셈 연산의 결과는 입력 피연산자 크기의 2배가 되므로, 상위/하위 레지스터에 나누어 저장됩니다.

```assembly
imul <source>                            ; RAX * <src> -> RDX:RAX에 저장
imul <destination>, <source>             ; <dst> = <dst> * <src>
imul <destination>, <source>, <imm>      ; <dst> = <src> * <imm>

```

#### 나눗셈 (`div` / `idiv`)

나눗셈 전 피젯수(Divided Value)를 레지스터 쌍에 미리 세팅한 뒤 수행합니다.

* **32비트 나눗셈 (`EDX:EAX / <src>`)**: 몫은 `EAX`, 나머지는 `EDX`
* **64비트 나눗셈 (`RDX:RAX / <src>`)**: 몫은 `RAX`, 나머지는 `RDX`

---

### 2) 논리 연산 (`and`, `or`, `xor`, `not`)

* **`and <dst>, <src>`**: 비트 단위 AND (특정 비트 마스킹)
* **`or <dst>, <src>`**: 비트 단위 OR (특정 비트 플래그 설정)
* **`xor <dst>, <src>`**: 비트 단위 XOR (레지스터 0 초기화 `xor rax, rax` 등에 매우 빈번하게 사용)
* **`not <dst>`**: 모든 비트 반전 (1의 보수)

---

## 1-6. 비교 연산 명령어

### 1) `cmp <destination>, <source>`

두 피연산자를 뺄셈(`<dst> - <src>`)하여 결과에 따라 플래그 레지스터(ZF, SF, OF 등)를 갱신합니다. (피연산자 값 자체는 변경되지 않음)

| `rax` 값 | `rbx` 값 | ZF (Zero) | SF (Sign) | 비고 |
| --- | --- | --- | --- | --- |
| 10 | 20 | 0 | 1 | `rax < rbx` (결과 음수) |
| 20 | 10 | 0 | 0 | `rax > rbx` (결과 양수) |
| 10 | 10 | **1** | 0 | `rax == rbx` (결과 0) |

### 2) `test <destination>, <source>`

두 피연산자를 비트 단위 **`AND`** 연산하여 플래그 레지스터를 갱신합니다. (주로 레지스터가 0인지 검사 `test rax, rax` 또는 특정 비트 설정 여부 확인 시 사용)

---

## 1-7. 분기문 (Branching)

비교 연산(`cmp`, `test`) 결과로 설정된 **플래그 레지스터** 상태에 따라 명령어 포인터(`RIP`)를 변경하여 실행 흐름을 제어합니다.

### 1) 무조건 점프: `jmp`

조건 없이 지정된 주소(레이블)로 이동합니다.

---

### 2) 주요 조건 점프 명령어 (Conditional Jump)

| 명령어 | 조건 (C 언어 대응) | 플래그 상태 |
| --- | --- | --- |
| **`je` / `jz**` | `==` (Equal / Zero) | `ZF == 1` |
| **`jne` / `jnz**` | `!=` (Not Equal) | `ZF == 0` |
| **`jg` / `jge**` | `>`, `>=` (Signed Greater) | `ZF == 0` & `SF == OF` |
| **`jl` / `jle**` | `<`, `<=` (Signed Less) | `SF != OF` |
| **`ja` / `jae**` | `>`, `>=` (Unsigned Above) | `CF == 0` & `ZF == 0` |
| **`jb` / `jbe**` | `<`, `<=` (Unsigned Below) | `CF == 1` |

---

## 1-8. 반복문 (Loop) 구현 패턴

### C 언어 vs 어셈블리 반복문 패턴

#### C 언어 코드

```c
int cnt = 0;
int sum = 0;
while (cnt <= 100) {
    sum++;
    cnt++;
}

```

#### 어셈블리 변환 예시

```assembly
section .text
global _start

_start:
    xor rax, rax        ; sum = 0
    xor rcx, rcx        ; cnt = 0

for_loop:
    cmp rcx, 101        ; cnt와 101 비교
    jge loop_end        ; cnt >= 101 이면 루프 탈출

    inc rax             ; sum++
    inc rcx             ; cnt++
    jmp for_loop        ; 루프 처음으로 복귀

loop_end:

```

### 카운터 기반 `loop` 명령어

`loop` 명령어는 호출 시 내부적으로 **`RCX` 레지스터 값을 1 감소**시키고, `RCX != 0` 일 때 지정된 레이블로 점프합니다.

```assembly
mov rcx, 10             ; 반복 횟수 10 설정

loop_start:
    ; 반복할 작업 수행
    loop loop_start     ; RCX를 1 차감하고, RCX가 0이 아니면 loop_start로 이동

```
