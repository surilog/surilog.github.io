# [Dreamhack] rev-basic-5 핵심 연산 구조 분석

## 1. 개요 및 C 언어 제어 흐름 분석

### `main()` 함수 제어 구조

```c
int __fastcall main(int argc, const char **argv, const char **envp)
{
    char v4[256];

    memset(v4, 0, sizeof(v4));
    sub_1400011C0("Input : ", argv, envp);
    sub_140001220("%256s", v4);
    if ( (unsigned int)sub_140001000((__int64)v4) )
        puts("Correct");
    else
        puts("Wrong");
    return 0;
}

```

* `v4` 버퍼(256바이트)를 `0`으로 초기화한 후 사용자 입력값을 수신합니다.
* 입력 문자열을 검증 로직인 `sub_140001000()` 함수에 전달하여, 반환값 참/거짓 여부에 따라 성공/실패 메시지를 출력합니다.

---

### `sub_140001000()` 조건식 분석

```c
int __fastcall sub_140001000(char *a1)
{
    int i;

    for ( i = 0; (unsigned __int64)i < 0x18; ++i )
    {
        if ( ((unsigned __int8)a1[i + 1] + (unsigned __int8)a1[i]) != byte_140003000[i] )
            return 0LL;
    }
    return 1LL;
}

```

* **핵심 조건 검증**: `a1[i + 1] + a1[i] == byte_140003000[i]` ($i = 0 \sim 23$)
* **의미**: 입력받은 문자열 배열에서 **연속된 두 인덱스 원소의 ASCII 합**이 바이너리 내부 정적 메모리 배열(`byte_140003000`)의 값과 일치하는지 순차 검증합니다.

## 2. 연산 논리 유도 (방정식 및 점화식)

입력 문자열 배열을 $a1$, 정적 데이터 배열을 $data$라 할 때, 루프 내 조건식은 다음과 같습니다.

$$a1[i + 1] + a1[i] = data[i]$$

### 역산(Backtracking) 점화식 전개

현재 인덱스 $a1[i]$의 값을 구하기 위해 $a1[i+1]$을 이항하여 식을 정리합니다.

$$a1[i] = data[i] - a1[i + 1]$$

* **Null Terminator($\text{\textbackslash 0}$) 기저 조건**:
1. 연산 대상 문자열의 길이는 총 24자 ($a1[0] \sim a1[23]$)입니다.
2. C 언어 문자열 끝에는 항시 Null 문자가 결합하므로 **$a1[24] = 0$** 이 보장됩니다.
3. 이를 통해 $i = 23$ 지점에서의 기저 조건(Base Condition)을 도출할 수 있습니다.

$$a1[23] = data[23] - a1[24] \implies a1[23] = data[23] - 0 = data[23]$$

## 3. 알고리즘 의사코드 (Pseudocode Concept)

가이드라인에 따라 실행 가능한 코드 대신 연산의 핵심 구조를 표현한 의사코드 스니펫입니다.

```python
# 역추적 알고리즘 개념 스니펫 (Pseudocode)

# 1. 기저 조건 설정: 문자열 종료 문자(Null)의 인덱스 위치는 0
a1[24] = 0

# 2. 마지막 인덱스(i = 23) 기저값 확정
a1[23] = data[23] - a1[24]

# 3. 인덱스를 역순(22 -> 0)으로 순회하며 이전 원소 복원
for i in range(22, -1, -1):
    # Unsigned 8-bit 오버플로우/언더플로우 보정을 위한 256 모듈로 연산
    a1[i] = (data[i] - a1[i + 1]) % 256

```

## 4. 핵심 정리

1. **검증 범위**: 256바이트 입력 버퍼 중 실제 연산에 참여하는 핵심 구간은 $0 \sim 23$ 인덱스(총 24바이트)입니다.
2. **역추적 알고리즘**: 두 인덱스의 합으로 얽힌 조건식은 알려진 종단값($a1[24] = 0$)으로부터 역순 계산할 때 유일한 해가 결정됩니다.
3. **8비트 모듈로 보정**: 파이썬 등 임의 정수형 언어에서 뺄셈 연산 시 발생할 수 있는 음수 연산은 `% 256` 모듈로를 통해 C 언어의 `unsigned __int8` 타입 오버플로우 동작 방식을 정확히 구현할 수 있습니다.
