# [Dreamhack] rev-basic-7 핵심 연산 구조 분석

## 1. 개요 및 함수 분석

* `main()` 함수는 표준 입력을 통해 256바이트 버퍼를 수신하고 검증 함수 `sub_140001000()`의 반환값에 따라 성공/실패 여부를 출력합니다.
* 핵심 연산 로직이 담긴 `sub_140001000()` 디컴파일 코드 분석이 필요합니다.

### `main()` 함수 제어 구조

```c
int __fastcall main(int argc, const char **argv, const char **envp)
{
    char v4[256];

    memset(v4, 0, sizeof(v4));
    sub_140001120("Input : ", argv, envp);
    sub_1400011B0("%256s", v4);
    if ( (unsigned int)sub_140001000((__int64)v4) )
        puts("Correct");
    else
        puts("Wrong");
    return 0;
}

```

---

### `sub_140001000()` 디컴파일 분석

```c
__int64 __fastcall sub_140001000(__int64 a1)
{
    int i;

    for ( i = 0; (unsigned __int64)i < 0x1F; ++i )
    {
        if ( ((unsigned __int8)__ROL1__(*(_BYTE *)(a1 + i), i & 7) ^ i) != byte_140003000[i] )
            return 0LL;
    }
    return 1LL;
}

```

* **수식 정리** ($i = 0 \sim 30$, 총 31회 순회):

$$\left( \text{ROL1}(a1[i],\, i \ \& \ 7) \right) \oplus i == \text{byte\_140003000}[i]$$



#### 연산 기호 및 변수 정의

* **$a1[i]$**: 입력 문자열의 $i$번째 1바이트 (8비트)
* **$data[i]$**: 정적 메모리 배열 (`byte_140003000`)
* **$\text{ROL1}(x, n)$**: 8비트 Unsigned Integer의 왼쪽 순환 시프트 (Rotate Left)
* **$i \ \& \ 7$**: 비트 연산으로 $i \pmod 8$ 과 동일 (순환시킬 비트 수, $0 \sim 7$)

### 역산 방정식 유도 (ROR 및 XOR 상쇄)

1. 양변에 $i$를 XOR 연산하여 오른쪽 항의 $i$를 상쇄시킵니다:

$$\text{ROL1}(a1[i],\, i \ \& \ 7) = data[i] \oplus i$$


2. 양변에 `ROL1`의 역연산인 오른쪽 순환 시프트(ROR1)를 적용하여 본래의 문자 $a1[i]$를 도출합니다:

$$a1[i] = \text{ROR1}(data[i] \oplus i,\, i \ \& \ 7)$$



---

### 파이썬에서의 8비트 ROR1(오른쪽 순환 시프트) 연산 모사

파이썬은 무제한 정수형 타입을 사용하므로 C 언어의 8비트 레지스터 레벨 순환 시프트를 모사하기 위해 비트 이동과 모듈로 마스킹(`& 0xFF`)을 조합합니다.

$$\text{shift} = i \ \& \ 7$$

$$\text{ROR1}(val, \text{shift}) = \left( (val \gg \text{shift}) \mid (val \ll (8 - \text{shift})) \right) \ \& \ 0\text{xFF}$$

---

### 비트 연산 수동 검증 (Step-by-Step)

#### ① $i = 0$ 일 때 ($data[0] = 0\text{x52}$)

* $\text{shift} = 0 \ \& \ 7 = 0$
* $a1[0] = \text{ROR1}(0\text{x52} \oplus 0,\, 0) = 0\text{x52}$ (ASCII 문자 `'R'`)

#### ② $i = 1$ 일 때 ($data[1] = 0\text{xDF}$)

* $\text{shift} = 1 \ \& \ 7 = 1$
* $val = 0\text{xDF} \oplus 1 = 0\text{xDE} \quad (1101\ 1110_2)$
* $\text{ROR1}(0\text{xDE}, 1)$: 오른쪽으로 1비트 순환 이동

$$1101\ 1110_2 \longrightarrow 0110\ 1111_2 = 0\text{x6F} \quad (111_{(10)} \rightarrow \text{'o'})$$



#### ③ $i = 2$ 일 때 ($data[2] = 0\text{xB3}$)

* $\text{shift} = 2 \ \& \ 7 = 2$
* $val = 0\text{xB3} \oplus 2 = 0\text{xB1} \quad (1011\ 0001_2)$
* $\text{ROR1}(0\text{xB1}, 2)$: 오른쪽으로 2비트 순환 이동

$$1011\ 0001_2 \longrightarrow 0110\ 1100_2 = 0\text{x6C} \quad (108_{(10)} \rightarrow \text{'l'})$$

## 3. 알고리즘 의사코드 (Pseudocode Concept)

가이드라인에 따라 완제 스크립트 대신 역산 로직의 흐름을 나타낸 의사코드 스니펫입니다.

```python
# 8비트 ROR(Rotate Right) 기반 역산 의사코드

for i in range(len(data)):
    shift = i & 7
    val = data[i] ^ i
    
    # 8비트 오른쪽 순환 시프트(ROR1) 구현
    if shift == 0:
        ror = val
    else:
        ror = ((val >> shift) | (val << (8 - shift))) & 0xFF
        
    a1.append(ror)

```

## 4. 핵심 정리

1. **순환 시프트(Rotate Shift) 특징**: 비트가 밀려나면서 반대편으로 다시 들어오는 `ROL1` 연산은 역연산인 `ROR1`을 적용하여 원본 비트 배열을 상쇄 및 복원할 수 있습니다.
2. **동적 비트 이동량**: $i \ \& \ 7$ 연산으로 인해 인덱스가 증가함에 따라 비트 시프트 이동량이 $0 \sim 7$ 주기(8-bit Cycle)로 매번 변동하므로, 역산 시 각 인덱스별 $i$ 값을 정확히 대입해야 합니다.
